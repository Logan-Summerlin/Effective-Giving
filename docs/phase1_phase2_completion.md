# Phase 1 and Phase 2 Completion Matrix

This matrix maps the roadmap exit gates to committed artifacts. It records implementation completion, not completion of charity evaluation.

## Phase 1 — Research and Governance Foundation

| Roadmap requirement | Implementation |
|---|---|
| Create/update README | `README.md` states scope, status, guardrails, repository map, and contributor workflow. |
| Methodology directory | `docs/methodology/` contains profile, evidence, cost-effectiveness, RFMF, conflicts, corrections, and research-governance rules. |
| Source registry template | `data/source_registry.csv` implements all required columns; source protocol explains use. |
| Charity profile schema draft | Narrative schema plus `data/schemas/charity_profile.schema.json`. |
| Cause-area evidence map template | `docs/templates/cause_area_evidence_map_template.md`. |
| Charity review template | `docs/product/charity_review_template.md`, with recommendation categories separately defined. |
| Cost-effectiveness draft | `docs/methodology/cost_effectiveness_model.md`; exposes assumptions, uncertainty, moral weights, sensitivity, and welfare/fiscal separation. |
| Room-for-more-funding method | `docs/methodology/room_for_more_funding.md`; scenarios include bottlenecks, funging, and spend-through. |
| Governance policy drafts | conflict, correction, independence, public-data, response, outside-review, reproducibility, and update rules are documented. |
| Exit gate | README and linked documents jointly explain product, permitted data, review structure, and credibility rules to a new contributor. |

## Phase 2 — Minimum Viable Data Prototype

| Roadmap requirement | Implementation |
|---|---|
| Select initial charities | `data/charity_selection.csv` contains exactly 50 unique EINs, 10 per cause area. |
| Register sources | 50 organization endpoint rows plus API documentation in `data/source_registry.csv`. |
| Extract IRS/Form 990 fields | Raw snapshots and normalized identity/latest-filing fields are generated by `scripts/build_charity_prototype.py`. |
| Create profile records | Canonical JSON and flat CSV are under `data/processed/`. |
| Flag missing/uncertain fields | Controlled field quality statuses; gaps summarized in `data_quality_report.json`. |
| Manually review a sample | `data/manual_review.csv` and `docs/phase2_manual_review.md` cover 10 stratified records. |
| Reproducibility and validation | Raw snapshots, generation script, JSON schema, and 10 automated tests. |
| Exit gate | 50 schema-conforming records exist with source provenance and quality flags; no record claims evaluation or recommendation. |

## Explicitly deferred

The following belong to later phases and are intentionally absent: intervention evidence-map findings, moral-weight numbers, cost-effectiveness estimates, funding-gap estimates, charity response requests, complete charity reviews, rankings, and recommendations. Publishing any of these from Phase 2 identity/financial data would violate the implementation plan.
