# Public Source Collection Protocol

Before using a source, add a registry row with source ID, name/type, exact URL, access method, retrieval date, license or terms notes, update frequency, fields extracted, limitations, and parsing confidence.

Prefer IRS exempt-organization records, Form 990 filings, state registries, audited statements, annual reports, government evaluations, grant databases, and public research literature. Candid/GuideStar and other providers may be used only within current access and licensing rules.

Retain an immutable raw snapshot when lawful and practical; otherwise retain a durable citation, checksum, retrieval log, and reason a copy is not stored. Never bypass access controls. Minimize personal information and do not collect confidential submissions under the current public-data-only policy.

For each normalized field, retain source ID, source period, extraction method, transform, quality status, and reviewer. If sources conflict, preserve both and explain resolution. A number without traceable provenance cannot be published as fact.
