Primary Data Sources
IRS Exempt Organizations Database
Government Registry Public Download
The IRS publishes the full list of organizations recognized as tax-exempt under Section 501(c) of the Internal Revenue Code. This database provides each organization's Employer Identification Number (EIN), legal name, address, subsection code, ruling date, and exempt purpose codes. It is the authoritative starting point for identifying which organizations are registered charities, confirming their legal status, and obtaining the EINs needed to retrieve further filings. Available as bulk data extracts at irs.gov.
IRS Form 990 Filings
Tax Filing Public
Most tax-exempt organizations with annual gross receipts above $50,000 must file Form 990 (or 990-EZ / 990-PF for private foundations) annually with the IRS. These filings report revenue, expenses, executive compensation, program service accomplishments, governance policies, and related-party transactions. The IRS makes machine-readable 990 data available via the AWS Open Data Registry. Form 990s are the primary source for financial transparency analysis — however, they report what money was spent on, not what outcomes were achieved.
ProPublica Nonprofit Explorer
Aggregated Public Data API + Web
ProPublica's Nonprofit Explorer provides a searchable interface and public API for IRS Form 990 data going back to approximately 2012. The API returns structured JSON for individual organizations and supports bulk lookups by EIN. It is particularly useful for retrieving recent 990 data before the IRS bulk extracts are updated, and for surfacing PDFs of original filings. Usage is subject to ProPublica's API terms of service; no registration is required for moderate query volumes.
Candid / GuideStar
Nonprofit Database Subscription (limited free)
Candid (formerly GuideStar) aggregates IRS filings alongside charity-submitted profiles, program descriptions, leadership information, seal-of-transparency ratings, and grant data from the Foundation Directory. The free tier provides basic organizational profiles; deeper financial history, grantee data, and API access require a paid subscription. Candid data may supplement 990 analysis with self-reported program narratives, but self-reported content is treated with lower confidence than audited financials or independent evidence. Access and licensing terms must be reviewed before bulk extraction.
State Charity Registries
State Government Varies by State
Most U.S. states require charities that solicit donations from residents to register with the state attorney general or a designated charity bureau, and to file annual renewal reports including audited financial statements and sometimes program narratives not required by the IRS. These registries are especially useful for charities operating below the IRS 990 disclosure threshold, for obtaining audited financial statements where the charity has not published them independently, and for identifying registration lapses or compliance actions. Access methods, data formats, and public availability vary significantly by state; some states provide bulk data downloads while others require case-by-case web requests.
Audited Financial Statements
Charity-Published Varies
Charities with sufficiently large budgets, or those receiving federal grants above specified thresholds, are required to commission independent audits of their financial statements. Audited statements provide a higher level of assurance than unaudited 990 data and typically include notes on accounting policies, significant estimates, related-party relationships, and — for federal grant recipients — findings from single audits under the Uniform Guidance. When available, audited statements are used to verify or adjust figures from 990 filings. Charities often publish audited statements on their own websites or through state charity registries; where neither source has them, we request them directly and record the outcome.
Source Registry
Every source used in a published evaluation is recorded in source_registry.csv. Each row captures: source name, URL, retrieval date, access method, license or usage notes, fields extracted, known limitations, and parsing confidence. This registry is published alongside evaluations to ensure full reproducibility. It is updated whenever new data is retrieved or a previously used source changes.
