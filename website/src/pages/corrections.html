Corrections Log

Every factual correction to our published evaluations, logged publicly.

Corrections Policy. Every factual correction to a published evaluation is logged here in full. Each entry records: the date the correction was made, the page or section affected, a description of the original error, a description of the correction applied, and whether the correction changed a charity recommendation. We do not quietly edit published content — all changes are documented below and the original text is preserved in version history. Disagreements about interpretation or methodology are handled separately and do not appear in this log.

How to Report an Error

If you believe a published evaluation contains a factual error — a wrong number, a misattributed finding, an outdated data point, or a mischaracterisation of a charity's program — please contact us. Send a brief description of the error, the page or section where it appears, and any source you believe contradicts the published claim. We review every report, aim to respond within five business days, and if a correction is warranted we will publish it here promptly. We welcome scrutiny: finding errors and correcting them publicly is central to how this project maintains credibility.

To report an error, email corrections@clearview.example with the subject line "Factual Error Report." Charities under evaluation may also use the dedicated charity response process described in our Methodology.
